# 金門返台交通助手

金門每年霧季（大約 3～5 月）常常整天停飛，學生放假返台、旅客要回本島時，只能一直刷航空公司網站、打電話問。這個專案把**航班即時狀態、金門能見度、濃霧特報、起霧預報、替代交通**整合在一個頁面，並用燈號告訴你「今天飛不飛得了、該怎麼辦」。

## 價值

- **使用價值**：金門大學有數千名學生，絕大多數放假要搭飛機返台，霧季停飛是每個人都遇過的痛點。開發者本身就是使用者。
- **商業價值**：同樣的需求也存在於每年上百萬人次的金門觀光客；可延伸為 LINE 通知訂閱、與民宿／旅行社合作推播改票資訊，或用同一套架構做馬祖、澎湖版本。

## 功能

| 功能 | 說明 |
|------|------|
| 停飛風險燈號 | 只依官方資料觸發：**濃霧特報、能見度、航班取消**，分為正常／請留意／可能停飛／停飛中，並列出判斷依據和建議。起霧推估和延誤不列入警告；資料抓不到時顯示「無法確認」，不會當成正常 |
| 今日航班概況 | 今天金門離境的總班次、已起飛、延誤、取消數 |
| 霧況與天氣 | 氣象署金門站能見度、天氣、溫濕度；金門的濃霧特報；未來 24 小時逐時起霧推估（依露點差、濕度、風速） |
| 航班動態 | 離境／抵達航班表，含**訂位狀態**（客滿／關櫃），可依航點篩選、搜尋航班號、隱藏已起飛 |
| 追蹤我的航班 | 點 ★ 追蹤，狀態改變時跳出提示，開啟瀏覽器通知後也會推播 |
| 替代方案 | 小三通今日每班船的時間與船名（下一班會標出來）、票價、訂位電話；金門大學、金城、山外到機場與水頭碼頭的公車即時到站 |

## 資料來源

| 資料 | API |
|------|-----|
| 金門機場離境／抵達即時航班、訂位狀態 | [金門航空站官網](https://www.kma.gov.tw/main/MoreDeparture.aspx)當日即時班表（主要來源） |
| 航班備援 | TDX `/v2/Air/FIDS/Airport/Departure/KNH`、`/Arrival/KNH`（官網讀不到或改版時自動切換） |
| 小三通船班表 | [交通部航港局每月公告](https://www.motcmpb.gov.tw/Information?SiteId=1&NodeId=543)的 PDF，由 `ships.py` 下載並解析 |
| 小三通航線、票價 | TDX `/v3/Ship/Route`（KMXM、KMQZ） |
| 金門公車即時到站 | TDX `/v2/Bus/EstimatedTimeOfArrival/City/KinmenCounty` |
| 能見度與天氣觀測 | 氣象署 `O-A0003-001`（金門站 467110） |
| 濃霧特報 | 氣象署 `W-C0033-010` |
| 鄉鎮逐時預報 | 氣象署 `F-D0047-085`（金湖鎮，尚義機場所在地） |

TDX 沒有金門航線的船班時刻，所以改從航港局下載：每月公告兩個 PDF（金廈、金泉），`ships.py` 用 `pdftotext` 轉成文字後解析成 `data/ships/YYYY-MM.json`。伺服器啟動時若缺當月資料會自動下載，每 12 小時檢查一次，每月 20 日後也會抓下個月的公告。如果某天的欄位數跟表頭對不上（停航、加班船），程式不會亂猜，會記在 `irregular_days`，請以原始 PDF 為準。

航班為什麼以官網為主：比對後發現 TDX 偶爾會在還沒起飛的航班填入「實際起飛時間」，而官網是機場自己的資料，還多了訂位狀態。官網沒有 API，所以用表頭文字定位欄位；格式對不上時不硬猜，直接改用 TDX。兩個來源都會在未起飛／未抵達的航班填入預估時間，程式只在狀態是「已起飛／抵達」時才顯示實際時間。

## 執行方式

需要 Python 3.8 以上，只用標準函式庫，不需要 `pip install`。更新船班表需要 `pdftotext`（Ubuntu：`sudo apt install poppler-utils`；macOS：`brew install poppler`）；沒裝也能執行，只是不會更新船班表。專案裡已附 2026 年 10、11 月的資料。

1. 申請金鑰（免費）：
   - TDX：<https://tdx.transportdata.tw> → 會員中心 → API 金鑰
   - 中央氣象署：<https://opendata.cwa.gov.tw> → 會員資訊 → 取得授權碼
2. 複製設定檔並填入金鑰：`cp .env.example .env`
3. 啟動：
   ```bash
   chmod +x start.sh
   ./start.sh          # 預設 8000 埠，可用 ./start.sh 8080 指定
   ```
4. 開啟 <http://localhost:8000/>

手動更新船班表：`python3 ships.py`。

## 架構

```
瀏覽器 (public/index.html)
   │  /api/status、/api/alternatives（每 2 分鐘自動更新）
   ▼
server.py ── 快取（記憶體 + cache/）── TDX（OAuth token 自動更新）
                                   └─ 中央氣象署
```

- **快取**：TDX 限流很嚴，所有使用者共用同一份快取（航班 2 分鐘、天氣 10 分鐘、預報 30 分鐘、公車 1 分鐘）；對 TDX 的請求排隊、間隔至少 1.5 秒。
- **容錯**：API 失敗或被限流時回傳上一次的資料，頁面上方顯示提示，不會整頁壞掉。
- **安全**：金鑰只存在 `.env`（已列入 `.gitignore`），只在後端使用，不會送到瀏覽器；網頁只能讀到 `public/` 裡的檔案。

## 檔案

| 檔案 | 說明 |
|------|------|
| `server.py` | 後端：API 代理、快取、風險判斷 |
| `ships.py` | 下載、解析航港局小三通船班表 PDF |
| `data/ships/` | 解析後的每月船班表 |
| `public/index.html` | 前端頁面 |
| `data/alternatives.json` | 替代方案設定：小三通航線說明、要顯示的公車路線與站牌 |
| `.env.example` | 金鑰設定範本 |
| `start.sh` | 一鍵啟動 |

## 限制與未來可做

- 起霧推估是經驗規則，不是官方預報；停不停飛以航空公司公告為準。
- 船班表依賴航港局 PDF 的版面，如果改版需要調整 `ships.py` 的解析規則。
- 推播通知需要頁面保持開啟；未來可改成 LINE Bot 或 Web Push，訂閱航班後關掉頁面也收得到。
- 可加入歷史停飛紀錄，統計「哪些月份、哪些時段最容易停飛」，幫助大家訂票。
