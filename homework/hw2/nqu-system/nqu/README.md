# 國立金門大學 校務行政資訊系統（模擬）

課程作業用的模擬系統，純前端 HTML / CSS / JavaScript，**沒有任何外部相依**（不需要 Node、不需要 npm、不需要連網）。

## 檔案

| 檔案 | 說明 |
|------|------|
| `index.html` | 登入頁（校徽圖已用 base64 內嵌，單檔即可運作） |
| `portal.html` | 登入後首頁＋所有查詢功能 |
| `啟動系統_Windows.bat` | Windows 一鍵啟動本機伺服器 |
| `start.sh` | macOS / Linux / WSL 一鍵啟動本機伺服器 |
| `assets/nqu-header.png` | 校徽橫幅原圖（備份用，頁面已內嵌不依賴此檔） |

## 執行方式

### 方式一：直接雙擊（最快）

把 `index.html` 和 `portal.html` 放在**同一個資料夾**，直接雙擊 `index.html` 即可。
網址列會是 `file:///...`，所有功能都正常。

### 方式二：起本機伺服器（網址是 http://localhost）

**Windows**：雙擊 `啟動系統_Windows.bat`

**macOS / Linux / WSL**：
```bash
chmod +x start.sh     # 第一次執行前給執行權限
./start.sh            # 預設 8000 埠，可用 ./start.sh 8080 指定其他埠
```

或手動下指令：
```bash
cd 這個資料夾
python -m http.server 8000
```
然後開瀏覽器到 <http://localhost:8000/index.html>

停止伺服器：在終端機按 `Ctrl+C`（或關掉那個視窗）。

> 若 8000 埠被占用，換一個號碼即可，例如 `python -m http.server 8080`。

## 已實作的功能

- **選課作業**：九個項目點進去皆顯示「非開放時間」
- **查詢 → 教務資訊查詢**
  - 學期成績查詢（114學年度第2學期／115學年度第1學期，可下拉切換）
  - 學生期中預警查詢（顯示無預警資料）
  - 歷年成績查詢（第三學年 115 ＋ 畢業學分審核）
  - 選課資料查詢（115-1 選課清單）
  - 課程資料查詢（課程規劃表，三個下拉選單：入學年／學制／系所）
- **查詢 → 跨域修習專區、學務資訊查詢**：模擬結果
- **登錄 / 申請**：學生基本資料表已實作，其餘顯示「功能建置中」
- 各報表頁面皆可直接用瀏覽器列印（已寫好列印樣式）

- 課程規劃表的內容目前是依歷年成績單推算的模擬資料，之後換成正式 PDF 的內容即可（在 `portal.html` 的 `CURRICULUM` 變數）。
